# ShimaneAI

島根県邑南町を拠点とするShimaneAIのホームページです。

## 構成

- `dist/index.html`：理念、事業内容、実績、ハッカソン、メンバー、無料相談、拠点情報
- `dist/styles.css`：レスポンシブレイアウトとスクロール演出
- `dist/script.js`：ナビゲーション、表示アニメーション、視差効果、相談先の接続
- `dist/contact-config.js`：公開する無料相談の受付先
- `dist/assets/`：写真とアイコン
- `vercel.json`：Vercel用の静的サイト設定

追加パッケージやビルド処理は不要です。Vercelの出力ディレクトリは `dist` です。

## 無料相談の受付先

現在は受付先が未指定のため、案内欄に準備中と表示します。名前やメールアドレスを収集したり、送信成功を表示したりする処理はありません。

公開するメールアドレスが決まった場合は `dist/contact-config.js` の `email` に設定してください。メール作成画面へ進むボタンに切り替わります。

既存の相談フォームを使う場合は同ファイルの `formUrl` にHTTPSのURLを設定してください。両方を設定した場合はフォームが優先されます。アカウント用の非公開メールアドレスやAPIキーは設定しないでください。

## GitHubとVercel

GitHubリポジトリを作成してこのソースを保存し、Vercelのプロジェクト設定でそのリポジトリを接続します。Production Branchを `main` にすると、mainへの更新を公開に反映できます。

現時点ではVercelへの直接デプロイを実施しています。GitHub連携の完了は別途確認が必要です。

## 演出とアクセシビリティ

スクロールに合わせた段階的な表示、写真の視差効果、見出しの登場演出、ページ内の読了位置を実装しています。OSの「動きを減らす」設定に従って演出を停止します。JavaScriptが無効でも本文を読めます。
